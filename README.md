# Rise in Pink — landing

Static landing page (HTML + CSS + JS, no build step).

- `index.html` — the page
- `*.jpg`, `*.png` — logos and photos (same folder as index.html)

## Publish with GitHub Pages
1. Create a new repository and upload `index.html` and all the images to the root.
2. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
3. The site goes live at `https://<user-or-org>.github.io/<repo>/` within a couple of minutes.

## Before going live
- Point the "Donate now" buttons (`href="#donate"`) to the real donation URL.
- Replace `[Beneficiary foundation]`, `[250,000]` and the FAQ placeholders.
- Update the social links in the footer.
